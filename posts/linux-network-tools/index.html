Linux 네트워크 확인 명령어

ip, ss, ping, traceroute 등 자주 사용하는 네트워크 점검 명령어를 정리합니다.
2026-08-21LinuxNetwork

명령어

ip addr, ip route, ss -tulpn, ping, traceroute를 중심으로 확인합니다.

사용 흐름

인터페이스 → 라우팅 → 소켓 → 목적지 도달 여부 순으로 점검하면 문제 범위를 빠르게 좁힐 수 있습니다.
