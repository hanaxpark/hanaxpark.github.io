[AWS SAA] Security Group과 NACL

상태 저장 여부와 적용 범위를 기준으로 Security Group과 NACL을 비교합니다.
2026-08-23CloudSecurity

핵심 차이

Security Group은 인스턴스/ENI 수준의 상태 저장 방화벽이고 NACL은 서브넷 수준에서 동작합니다.

시험 포인트

Allow/Deny 가능 여부와 Inbound/Outbound 처리 방식을 함께 비교합니다.
